## Objective
Write a Java program that accepts a year from the user and determines if it is a leap year. 

## Rules for a Leap Year
A year is a leap year if:
1. It is divisible by 4, AND
2. It is NOT divisible by 100, UNLESS
3. It is also divisible by 400.

## Instructions
1. Open `LeapYearChecker.java`.
2. Add your conditional logic where the `// TODO` comment is located.
3. Ensure your output exactly matches this format: `2024 is a leap year.` or `1900 is not a leap year.`
4. Commit and push your code to submit.
